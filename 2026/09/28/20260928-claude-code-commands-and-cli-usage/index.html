Claude Code 学习笔记：常用命令与 CLI 深度使用

发表于 2026-09-28

为什么学 Claude Code

把 Claude Code 作为最重要的 AI Agent 工具来学习，原因有二：一是它是不同于 ChatGPT 的 Agent 模式的集大成者，二是它拥有最好的模型。

这篇笔记整理了 Claude Code 的两块核心内容：会话内的斜杠命令，以及命令行下的深度用法（参数与管道）。

会话内命令

会话内命令以 / 开头，覆盖会话管理、配置、诊断、扩展等场景：

命令 说明
/init 创建 CLAUDE.md
/compact 压缩上下文，可指定参数，例如”保留关于设计的讨论”
/clear 清空上下文，开始新任务时使用
/export xxx.md 将会话内容导出为文档
/cost 看 token 消耗
/status 以下三个都是一样的
/usage
/config
/model 会话中切换模型
/help 查看所有命令
/doctor 检查安装健康状况，排查问题用
/permissions 查看/修改工具权限
/terminal-setup 配置终端快捷键（如 Shift+Enter 换行）
/vim 开启 vim 编辑模式
/theme 配色主题
/login、/logout 登录、登出
/release-notes 看看更新日志
/resume 恢复对话，会给出会话历史，自己选
/add-dir 把路径加入进来一起分析
/memory 编辑 claude.md 文件，会让用户选编辑全局的还是项目的
/mcp 查看和管理 MCP 服务器
/agents 管理子代理（subagent）
/tasks 查看命令
/exit 退出 cc，退出时会提示如何恢复这次对话的命令
/rewind 回退代码修改。按两次 esc，会打开更改列表，上下键选择回退的版本

日常使用频率最高的是 /clear 和 /compact 这一对：前者清空上下文开始新任务，后者在上下文将满时压缩并保留关键信息。

另外还支持自定义命令：在 .claude/commands 中定义一个 deploy.md，写明要做的操作，就可以在终端中直接使用这个命令，且支持参数定义。

! 开头则可以执行 shell 指令。

CLI 深度使用

常用参数

参数 说明
-p 完成后中断对话
—verbose 命令行尾部添加，会显示必要步骤（实测没有显示）
-c 继续上次退出 claude 前的 session（对话）
—output-format txt/json/stream-json 输出格式的定义，后两者查看起来很乱，主要是给 LLM 看的
—max-turns 限制对话轮数
—model 模型选择
—append-system-prompt “你是系统工程师” 附加说明
— cmd 指定工作目录
—resume \ 恢复指定会话，是 -c 的精确版（对应 /resume 命令）
—add-dir \<路径> 启动时额外添加可访问目录，对应会话中的 /add-dir 命令

其中 -p（print 模式）是自动化的关键：非交互执行，完成后直接输出结果并退出，适合脚本和管道场景。

--add-dir 也很实用。默认 claude 只能读写启动时所在的目录，如果项目要引用别处的文件（比如另一个仓库的代码），就用它把其他路径加进来。

小结

  • 会话内用 / 命令管理会话和配置，记住 /clear、/compact、/resume 就够日常使用了。
  • 命令行用 -p 加管道，可以把 claude 嵌入任何现有工作流，这是它区别于聊天框式 AI 的核心能力。
